# Bar Support for a High-Speed Filling Line

## Overview
Academic group project completed in 2025 for the course *Medios de Representación Gráfica II* at the National University of Lomas de Zamora, Argentina.

The project focused on CAD modeling and technical documentation for a bar support assembly intended for a high-speed filling line.

## Project Scope
- 3D modeling of mechanical parts from technical references.
- Design of a missing component as part of the assembly.
- Assembly modeling and exploded-view visualization.
- Preparation of construction drawings and an assembly drawing.
- Rendered views of the assembled mechanism and selected components.
- Assembly and disassembly videos.
